# Module 02 — Prompt engineering

Overview
- Practical techniques for writing prompts that produce useful, reliable outputs from models.

Learning objectives
- Understand prompt specificity, context, and constraints
- Use examples and few-shot prompting effectively
- Iterate and evaluate prompts to improve quality

Structure
- slides.md — core concepts and examples
- exercise.md — hands-on tasks for prompt iteration
- assets/ — optional supporting files (sample texts, datasets)

Estimated duration: 40 minutes (hands-on)
