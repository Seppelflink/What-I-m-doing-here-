# Module 03 — APIs & tools

Overview
- How to call models via APIs, use SDKs and CLIs, and safely integrate model calls into workflows.

Learning objectives
- Authenticate and call a model API from CLI or code
- Understand request parameters (temperature, max tokens), rate limits, and cost
- Parse model responses and handle errors and retries
- Use tooling: playgrounds, SDKs, and simple CLI clients

Prerequisites
- Modules 01–02 recommended
- A provider API key is optional; a configured local CLI or mock can be used instead

Structure
- slides.md — concepts, examples, and best practices
- exercise.md — hands-on API tasks
- assets/ — optional sample inputs or small test data

Estimated duration: 45 minutes (hands-on)
