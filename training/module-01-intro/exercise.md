# Module 01 — Exercise: Prompt design basics

Goal
- Compose and iterate 3 short prompts to generate useful text from a language model.

Steps
1. Pick a simple task (e.g., write a short bio, summarize a paragraph, generate a headline).
2. Draft an initial prompt that states the task, desired length, and tone.
3. Run the prompt in your preferred tool (e.g., playground, CLI, Chat UI).
4. Refine the prompt to improve clarity or format (add examples or constraints).
5. Record both prompts and outputs for comparison.

Success criteria
- At least 2 of 3 prompts produce outputs that match the requested format and tone after 1–2 refinements.

Hints & tips
- If output is too long/short, add "in X words" or "in 2–3 bullet points".
- For structured output, request JSON or numbered lists.

Example
- Task: Create a short product blurb for a reusable water bottle in a friendly tone.
  Initial prompt: "Write a short blurb about a reusable water bottle."
  Refined prompt: "Write a 35–45 word friendly product blurb highlighting eco-friendly materials and dishwasher-safe convenience."

Reflection questions
- Which refinement changed the result most and why?
- Were there any surprising outputs or safety concerns?

Optional: share one prompt and its output in the project issues or PR for feedback.
