# Module 08 — Developing Securely

Overview
- Learn to identify security and privacy risks in an AI-powered application before release.
- Practice safeguards for secrets, user data, model inputs and outputs, dependencies, and human review.
- This module is free and public, like the other modules in this repository.

Learning objectives
- Map the data and trust boundaries in a small AI feature
- Identify risks such as prompt injection, sensitive-data exposure, leaked credentials, and unsafe model output
- Choose practical mitigations and explain their limits
- Create a short security checklist for development and release

Prerequisites
- Modules 01–05 (basic generative AI concepts and a simple demo app)
- No API key or running model is required

Structure
- slides.md — secure-development concepts and a practical checklist
- exercise.md — threat-model a fictional AI support-ticket summarizer
- assets/scenario.md — the application scenario
- assets/sample-review.md — one possible review; your answers may differ

Estimated duration: 45 minutes
