# Module 09 — Testing and Releasing

Overview
- Practice testing an AI feature with repeatable examples and clear expectations.
- Learn how to separate deterministic software checks from evaluation of variable model behavior.
- Prepare a release with a checklist, verified artifact, and a rollback plan.

Learning objectives
- Write test cases for normal, edge, and failure behavior
- Evaluate retrieval and generated answers separately
- Keep a small regression set and compare changes against expected behavior
- Create a release checklist that covers versioning, packaging, integrity, and rollback

Prerequisites
- Modules 03 and 05 (basic app and API concepts)
- Modules 06 and 08 are recommended (RAG and secure development)
- Node.js 18 or later for the hands-on RAG checks; no API key or extra package is required

Structure
- slides.md — testing strategy and release workflow
- exercise.md — test the existing RAG demo and prepare a release decision
- assets/test-plan.md — example test matrix and release checklist

Estimated duration: 45–60 minutes
