# Module 07 — Project planning with AI

Overview
- Use an AI assistant as an interviewer to turn a rough idea into a written project plan (`plan.md`).
- Practice the first phases of the software development life cycle: idea, audience, requirements, MVP scope, risks, platform, and tasks.

Learning objectives
- Describe a project idea as a problem, a benefit, and a target audience
- Separate must-have from nice-to-have features and define a minimal first version (MVP)
- Identify risks and assumptions early, and record them instead of hiding them
- Run a guided AI interview and review the resulting `plan.md` critically
- Keep secrets out of plans and repositories (variable names only, values in a local `.env`)

Prerequisites
- Modules 01–02 (basic prompting); no coding is required

Structure
- slides.md — the planning steps and how to work with an AI interviewer
- exercise.md — hands-on interview that produces a `plan.md`
- assets/ — sample plan

Interview script
- The full interview (German) is in the repository root: [steps.md](../../steps.md). It covers all 18 steps. This module uses steps 1–9.

Estimated duration: 45 minutes (hands-on)
