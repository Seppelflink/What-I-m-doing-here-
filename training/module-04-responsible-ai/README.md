# Module 04 — Responsible AI & Safety

Overview
- Core responsible-AI principles: fairness, privacy, transparency, and accountability.
- Practical guardrails for model use and deployment, and how to evaluate risks.

Learning objectives
- Recognize common harms (bias, privacy leakage, hallucination) and mitigation strategies
- Apply simple evaluation checks and red-teaming prompts
- Design minimal safety policies and human-in-the-loop flows for a small project

Structure
- slides.md — concepts, case studies, and recommended practices
- exercise.md — hands-on bias-detection, evaluation checklist, and mitigation steps
- assets/ — (optional) example prompts, datasets, or test cases

Estimated duration: 45 minutes (lecture + hands-on)
